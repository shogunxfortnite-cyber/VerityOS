# Verity OS

Verity OS is a WebOS project I made for the Stardance WebOS 1 competion.

I wanted to make a simple operating system that looks futuristik but is still easy to use. The main feature of the OS is Verity AI.

## Verity AI

Verity AI is a offline assitant inside Verity OS. It dosnt need a API key or internet connection.

It can do things like:

* Tell the time
* Tell the date
* Do basic calculashions
* Open some apps
* Answer basic questions
* Show the commands it knows
* Give some small fun facts

Some example commands are:

help
time
date
calculate 25*4
open notes
open calculator

It is not a full AI model like ChatGPT but I made it to act like a assitant inside the OS.

## Apps

Verity OS has a few diffrent apps.

Files
A simple file browser for the system.

Notes
A basic notes app where notes can be saved localy.

Calculator
A simple calculator for doing calculashions.

Settings
Contains some basic settigns for the OS.

About
Shows information about Verity OS.

## Windows

The apps open in windows that can be moved around.

Windows can also be minimised and closed. They can be opened again from the taskbar.

I wanted the windows to make it feel more like a real OS and not just a normal web page.

## Design

The OS has a dark simple design with glass style windows and a futuristik background.

It also has:

* A boot screen
* A taskbar
* An app launcher
* Notifications
* A live clock
* Draggable windows

## Offline

The whole project is inside one HTML file.

It dosnt need:

* An API
* A server
* External libreries

The Notes app also uses local storage to save notes in the browser.

## How to run

Open the Verity_OS.html file in a browser.

The boot screen will come first and after that the desktop should load.

## Main custom feature

The main custom feature of this project is Verity AI.

I made it as a part of the operating system so it can also open some other apps by using commands.
