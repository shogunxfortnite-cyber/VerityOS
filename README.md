# Verity OS

## A futuristic, local-first WebOS built for Stardance WebOS 1

Verity OS is a fictional operating system designed to feel like a modern, futuristic desktop while remaining completely self-contained in a single HTML file.

The main feature of Verity OS is **Verity AI**, a lightweight offline assistant that works directly inside the operating system without requiring an API key or internet connection.

## ✦ Features

### Verity AI

Verity AI is the built-in offline assistant for Verity OS.

It can:

* Respond to basic conversations
* Tell the current time and date
* Perform simple calculations
* Open apps using commands
* Explain what Verity OS is
* Provide built-in facts and information
* Show available commands with `help`

Example commands:

`help`

`time`

`date`

`calculate 25*4`

`open notes`

`open calculator`

## 🖥️ Built-in Apps

### Files

A simple local file browser interface showing the Verity workspace.

### Notes

A note-taking application with local saving using browser storage.

### Calculator

A built-in calculator supporting basic mathematical operations.

### Settings

Controls for features such as local-first mode, glass effects, and notifications.

### About

Displays information about Verity OS and its version.

## 🪟 Window System

Verity OS includes a desktop-style window manager.

Windows can be:

* Dragged around the desktop
* Minimized
* Closed
* Reopened from the taskbar
* Brought to the front by clicking them

## 🎨 Design

Verity OS uses a futuristic visual style inspired by modern operating systems.

The interface includes:

* Glass-style windows
* Cyan and violet accents
* Animated boot screen
* Futuristic desktop
* App launcher
* Taskbar
* Notifications
* Live clock
* Responsive layout for smaller screens

## 🔒 Offline & Privacy

Verity OS is designed to work locally.

There are:

* No API keys
* No external libraries
* No required server
* No required internet connection for the core experience

The entire project is contained inside one HTML file.

## 🛠️ Technology

Verity OS is built using:

* HTML
* CSS
* JavaScript
* Browser Local Storage

No frameworks are required.

## 🚀 Running Verity OS

Open `Verity_OS.html` in a modern web browser.

The system will automatically show the Verity OS boot screen and then load the desktop.

## 🌟 Custom Feature

The major custom feature of this project is **Verity AI**, an integrated offline assistant designed specifically for the operating system.

Instead of simply being another app, Verity AI acts as a central assistant that can interact with the other applications in Verity OS.

## 📌 Project Goal

The goal of Verity OS is to create a WebOS that feels like a real operating system rather than just a collection of webpages.

The design focuses on:

**Truth. Simplicity. Intelligence.**
